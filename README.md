# Startpos Best Runs


This mod shows a <cy>NEW BEST</c> popup after new best <cr>from start positions</c>

## Other features:
- Conveniently **displays and sorts** all best runs on a level
- Allows setting the level's gameplay end percentage. All progress values will be adjusted accordingly. This is useful, for example, for Amethyst, where gameplay ends at 83%
- Option to display progress values with 2 decimal places
- Ability to customize the **Best Run** popup template. Default is ``{start}%-{end}%``
- Doesn't save noclip or speedhack runs
- Saves zero-death noclip runs (e.g. a 12%-84% noclip run with no deaths will be saved)
